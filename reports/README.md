## 🚀 Quick Start

If you're completely new, follow this path:

1. **Install** (1 minute)
   ```bash
   pip install -r requirements.txt
   ```

2. **Test** (2 minutes)
   ```bash
   python test_simple_pipeline.py
   ```

3. **Run** (1 minute)
   ```bash
   python simple_inference.py --video YOUR_VIDEO.mp4 --model YOUR_MODEL.ckpt
   ```

4. **Learn More** (optional)
   - Read `simple_video_pipeline_report.md` for details
   - Try `../examples/simple_video_inference.ipynb` for interactive learning
